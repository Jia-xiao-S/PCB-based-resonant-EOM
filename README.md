# PCB-based Resonant Electro-Optic Modulator

This repository provides the open-source hardware design files for a PCB-based resonant electro-optic modulator (EOM).

## Included Files

### PCB Gerber files
- Upper PCB Gerber files
- Bottom PCB Gerber files

These files can be used for PCB fabrication.

### Aluminum-alloy shielding enclosure
- STEP model of the aluminum-alloy shielding enclosure

The STEP model can be used for mechanical fabrication and integration of the PCB-based resonant EOM.

## Description

The device is a PCB-based resonant phase electro-optic modulator designed for laser phase modulation and sideband generation.

Its resonant frequency can be adjusted by changing the RF transformer module and tuning the variable capacitor.
